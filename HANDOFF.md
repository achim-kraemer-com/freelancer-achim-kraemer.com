# Projekt-Kontext: freelancer-achim-kraemer.com (Freelancer-Pro)

> Handoff-Zusammenfassung für einen neuen Chat / weitere Bearbeitung.

## Überblick
Neue Symfony-App als **Freelancer-Pro**: Verwaltung von **Kunden → Projekten → Aufgaben → Rechnungen (PDF)**. Login-Bereich im Design von achim-kraemer.com (dunkles Glassmorphism, Lexend-Font, violette Akzente). Liegt im Repo `freelancer-achim-kraemer.com`, die eigentliche App im Unterordner **`application/`**.

## Stack
- **Symfony 8.1 / PHP 8.5**, Doctrine ORM + Migrations, **MariaDB 10.6**
- Security-Bundle (`form_login`, CSRF, remember-me, Access-Control), Symfony Form, Twig
- **Buildloses CSS** (kein Webpack/Tailwind) in `application/public/css/app.css`
- PDF-Rechnungen mit **`setasign/fpdi` + `tecnickcom/tcpdf:^6.7`** (6.x zwingend — tcpdf 7.x bricht FPDI mit „unable to read file: helvetica.json")

## Domänenmodell
- **Customer** — vollständige Kontaktdaten (Name, Firma, E-Mail, Telefon/Mobil, Adresse, Website, aktiv)
- **Project** — gehört zu Customer, hat Name + Beschreibung
- **Task** (Aufgabe) — gehört zu Project; entweder `hours` (× **60 €/Std.**, `Task::HOURLY_RATE`) **oder** fester `price`. `getCost()` rechnet automatisch; `isHourly()` = price null & hours gesetzt
- **Invoice** — aus mehreren offenen Tasks **eines** Projekts; Status **erstellt → verschickt → bezahlt** (`Invoice::STATUS_*`). Abgerechnete Tasks werden gesperrt (`invoiced=true`). Feld `template` (`App\Enum\InvoiceTemplate`): **Achim Krämer** oder **Mirwena** — bestimmt das Blanko-PDF (Briefkopf/Logo), wird beim Erstellen auf der Projektseite gewählt. Feld `signature` (ManyToOne `MailSignature`, nullable, `ON DELETE SET NULL`): die E-Mail-Signatur, mit der die Rechnung verschickt wird
- **MailSignature** — E-Mail-Signatur nach dem Vorbild von portal.achim-kraemer.com (dort `MailSignature`/`MailSignatureController`): `label`, `text`, `format` (`text`|`html`), `position`, `defaultForTemplate` (nullable `InvoiceTemplate` — Vorgabe je Briefkopf, nur eine je Vorlage; `SignatureController::keepDefaultUnique`). Signaturen sind global (kein Owner), da Rechnungen/Kunden ebenfalls allen Admins gehören. `asBlock()` = Textfassung hinter `-- `, `asHtml()` = HTML-Quelltext (nur bei HTML)
- **AssistantModel** — ein angeschlossenes Sprachmodell für KI-Suche und Assistent: `label`, `provider` (`anthropic` | `openai`), `model`, `baseUrl` (leer = Vorgabe des Anbieters), `apiKey` (**verschlüsselt**, `SecretCipher`), `reasoningEffort` (nur OpenAI-kompatibel), `isDefault`, `position`, `lastCheckedAt`/`lastError` (Verbindungstest). Gehört **einem Benutzer** (`owner`, `ON DELETE CASCADE`) — anders als Kunden/Rechnungen, die allen Admins gemeinsam gehören: Der Schlüssel ist seiner, und abgerechnet wird darüber
